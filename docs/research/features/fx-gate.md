# FX Loop gate (`HX_FX_GATE=1`, `src/sharc/fx_gate.asm`, `tools/patch_gate.py`, `tools/features/fx_gate.py`)

Issue #69: a noise gate built into the FX Loop and Return blocks. Status tags as in [conventions.md](../conventions.md); the facts are in [sharc/cores/gates.md](../sharc/cores/gates.md).

- Decided (2026-11-14): the gate goes on the stock models, with their Static Model Table cost raised by the gate's, it gates the return only (no Pre/Post), the Mixer gets none, and the web page offers it unticked (`WEB = 'opt-in'`). The cost was first the Noise Gate block's (150 mono, 190 stereo); the wrapper costs about 260 cycles a block a reader, so it is 20 a reader [hypothesis: not measured].
- First design, a `0x2720` member inserted in the four composites: blocks went dead whenever the new member was bound (noise-gate-1..11, RAM runs measured over USB; what each changed is in gates.md). Second design, a wrapper around the return reader: works [verified on unit, noise-gate-12 `4c259806…`, noise-gate-13 `b68052ee…`]: with Gate On and Threshold −30 dB the hiss between plucks (−45 dB) goes to digital silence and the plucks pass; Gate Off or a threshold under the hiss passes it; Decay 1 s closes slower; FX Loop 1/2 gates likewise.
- How it was measured: the Input block on USB 5/6 by rewriting the edit buffer (`hx_ctl.py` load-preset, Input key 5 = 6), plucks over hiss played into USB 5/6 from the Mac, USB 1/2 recorded, a cable from Send L/R to Return L; a block is alive when Return −60 dB drops the output by 60 dB.
- Builds [verified offline]: `HX_FX_GATE=1` MD5 `ebd17817…`; with `HX_GR`, `HX_CLICK`, `HX_REAL_NAMES` `190ef117…` (since #111, `tools/block3.py`: the gate alone sits at the top of the room, and the GR meter under the gate). Before #111: `e76a1702…`, `dff2ee81…`.
- Not yet checked on the unit: the knobs on the screen and after a preset save, HX Edit with the extra knobs, a gate build with the GR meter and Metronome together, the DSP cost.
