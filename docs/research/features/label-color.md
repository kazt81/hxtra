# Label color (`HX_LABEL_COLOR`, `tools/features/label_color.py`, `src/m4/label_color.s`)

HXtra settings' and block parameters' labels in Teal (`0x3cceb5`, Tap LED Color's Teal), so they read apart from the stock white ones; in every web build. Each label is coloured by the call that draws it, so nothing repaints on its own. Status tags as in [conventions.md](../conventions.md).

- **Global Settings labels** [verified offline: disassembly, emulated handlers]: the section paint `0x28dce854(view)` loops over its three slots; for each non-empty one it fetches the long label (`0x28d97634`), then colours it white with `0x28dc6454(slot, 0xffffff)` at `0x28dce962` and sets the text with `0x28dc63d0(slot, label)`. The slot's setting ID (from `0x28dce650(view, slot)`) is in r5 at the colour call. `0x28dc6454` is `setColor` (`0x28e24a28`) on the slot's label text widget, `0x281f7370 + 0x30 * (slot + 3)`. The value text (`0x28dc6568`, `0x281f76a8 + 0x30 * slot`) is grey `0x979797`. A knob turn repaints only the value (`0x28dce6e0`), so the label keeps its colour. The feature owns that call (`own_call`) and gives a virtual ID (`0xcc..0xf9`, every HXtra setting) Teal; any other ID keeps white.
- **The Global Settings view** [verified offline]: `0x2812957c`, list A, registered at `0x28d96cde` with the generic list A paint `0x28d947c9` (literal `0x28d96e38`, shared with nine other views) and the handler `0x28dcf40d`, which ends in the section paint when `[view+0x44]` is 0 and in `0x28dce9b4` when it is 1.
- **The tuner's page** [verified on unit, `label-color-6`]: tuner.s paints its own page (Activate, Lock) and colours its labels from its own table; with label_color built (ORDER -1, so before tuner), tuner.py points that table's label row at label_color's `label_any`, which gives Teal; without it the row is the stock `0x28dc6455` and tuner.s assembles to the same bytes as before (`tests/test_tuner.py`).
- **Rainbow, dropped** [verified on unit, 2026-11-17, `label-color-1` .. `-5`]: a Rainbow that recoloured the labels shown every 60 ms (from the LED task's 1 ms tick, recolouring before the generic list A paint `0x28d947c9`) first left black rectangles where a label's erase overlaps the slot's value bar (`0x281f77b0 + 0x5c * slot`, node `[+0x58]`); marking the bar and value nodes dirty with the ROM's `0x10003468(node)` under its widget lock (`0x10003478` / `0x10003484`) fixed that, but labels still flashed black or blank while values were turned quickly, in Global Settings, the Edit view and the tuner page, and Teal (no repaint of its own) never did. Rainbow was dropped for Teal (23:11); a picked colour is a later issue.
- **Block parameters** [verified offline: disassembly, emulated handler]: the Edit view's parameter knob drawer `0x28dbf5c4(knob, ui index, block info, full)` sets the label text with `0x28dc63d0(knob, buffer)` at `0x28dbf800`, only on a full draw (its 4th argument, `[sp+0x14]`, tested at `0x28dbf728`); the page loops colour each knob's label white before (`0x28dbfd5a`, `0x28dbfa0a`, `0x28dbfa54`). There r5 is the block info (`0x28e0fafc`: bytes 1..4 the first model's preset ID, 5..8 the second's or -1), and `0x28dbe830` has left the parameter's index within its model at `[sp+0x6c]` and, at `[sp+0x70]`, 1 when it is the block's second model's. The feature owns that call: a parameter at or past its model's first HXtra index (a build-time table of preset IDs: each GR compressor's own parameter count, 0 for NAM and the Metronome, 181) gets Teal first; any other keeps the page loop's white. patch_amp's ir-title cave (site B `0x28dbf72e`, back at `0x28dbf7e6`) runs after it. The UI index is the parameter's position in Entry 3's list: the GR knobs, appended last, start at the compressor's old count [verified on unit, label-color-2].
- **On the unit** [verified on unit, 2026-11-17, `label-color-2` (Rainbow), `label-color-6` and the final `label-color-7` (Teal, all features, payload MD5 `feb4bc0ccd2a5f85bb5b53abb1962cae`)]: in Global Settings the HXtra labels are coloured and the stock ones stay white; the GR knobs on Deluxe Comp and Red Squeeze, every NAM knob (Model too, with the IR-name title as before) and every Metronome knob are coloured; a stock IR and an Amp+Cab stay white; the tuner page's labels are Teal from its first paint; fast value changes show no flicker in Teal.
- **Tests**: `tests/test_label_color.py`.
